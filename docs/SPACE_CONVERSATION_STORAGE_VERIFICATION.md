# Conversation Space delivery-service verification

This work adds immutable storage placement and ordered references for conversation history stored in sender-owned Spaces. The delivery service checks the encrypted batch transiently, but stores only the source identity, CID, authenticated order and retention metadata. Existing DS-hosted histories keep their original placement and ciphertext. Local admission/deletion tests, real Swift-to-Rust policy/deletion requests, and the bounded native storage lifecycle against actual local Swan and reference-PDS processes have passed. CI repairs and the remaining production and app/device checks are recorded separately below.

**This branch is not release-ready.** The exact existing CI dependency-audit command fails with 23 vulnerability entries and one denied warning. Runtime dependency versions and the audit ignore list remain unchanged; remediation requires a separately qualified successor.

The governing design is [Labyrinth's MLS DS backend](../../labyrinth/docs/MLSDS_BACKEND.md). Configuration and wire behavior are in [Conversation Space storage](SPACE_CONVERSATION_STORAGE.md), with provisional choices in [the decision log](DECISIONS.md).

Resolver destinations, transport trust, caching, endpoint/nonce admission and P-256 parsing are unchanged. See the [decision log](DECISIONS.md) for the explicit compatibility choice.
